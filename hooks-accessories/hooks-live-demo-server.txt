# Real terminal output from actually installing and running every
# SERVER-SIDE hook in this repo (installed into a bare repository's own
# hooks/, not a client's .git/hooks/ - see README "Hooks" for why).
# Client-side hooks are in the sibling file
# hooks-accessories/hooks-live-demo-client.txt.
#
# Nothing below was typed by hand: each block is copied verbatim from
# running the real Git command against a throwaway bare/non-bare "server"
# repo with the real hook script installed, author MichalS16. Where a
# hook can both accept and reject something, both real outcomes are
# shown. Long scratch-repo paths have been shortened to `<remote>`/
# `<server>`/`<deploy_target>` for readability; nothing else was edited.
#
# See THEORY.md for what each hook is for and hooks/server-side/ for its
# full commented source.

--------------------------------------------------------------------------

local changes, so it refuses to overwrite them (the push itself is still
accepted into the repo - only the working tree update is refused)
--------------------------------------------------------------------------
$ git push origin main

HOOK - PUSH-TO-CHECKOUT (server-side) - updating working tree to e07d75bb684f034f317f00bd074e2846151ea144

To <server>
 ! [remote rejected] main -> main (push-to-checkout hook declined)
error: failed to push some refs to '<server>'
