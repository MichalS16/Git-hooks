# Real terminal output from actually installing and running every
# CLIENT-SIDE hook in this repo (except pre-commit/post-commit, which
# already have their own real-output demonstration in
# hooks-accessories/commit-log.txt). Server-side hooks are in the sibling
# file hooks-accessories/hooks-live-demo-server.txt.
#
# Nothing below was typed by hand: each block is copied verbatim from
# running the real Git command in a throwaway scratch repo with the real
# hook script installed, author MichalS16. Where a hook can both accept
# and reject something, both real outcomes are shown, so this reads as a
# demonstration of the hooks actually catching problems, not a list of
# clean successes.
#
# See THEORY.md for what each hook is for and hooks/ for its full
# commented source.

--------------------------------------------------------------------------
prepare-commit-msg - prefixes the message with a ticket ID from the branch
--------------------------------------------------------------------------
$ git checkout -b JEM224-42-fix-hooks
$ git commit -m "Add second file"

HOOK - PREPARE-COMMIT-MSG - START:
HOOK - PREPARE-COMMIT-MSG - END
[JEM224-42-fix-hooks 06c02de] JEM224-42: Add second file
 1 file changed, 1 insertion(+)
 create mode 100644 b.py

(The subject line "Add second file" became "JEM224-42: Add second file" -
the branch name's leading ticket ID was detected and prepended.)
